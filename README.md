# CULTURA DE RUA

**A rua é de todos. A cultura também.**

Plataforma colaborativa dedicada à cultura urbana, começando por Ribeirão Preto e região.

## Estado atual

Esta é a primeira base visual do projeto, construída a partir do repositório originalmente chamado GraffitiSart.

- Página inicial responsiva, com prioridade para dispositivos móveis.
- Identidade visual escura com acentos vibrantes inspirados na arte urbana.
- Navegação principal e menu móvel.
- Mural demonstrativo com filtros por categoria.
- Seções iniciais para Agenda, Vitrine, Cena Local e Revista.

## Importante

O conteúdo do mural é ilustrativo. Login, cadastro, banco de dados, publicação de conteúdo, perfis, mensagens, agenda funcional e demais recursos da plataforma ainda não foram implementados nem testados.

## Princípios

- Acesso gratuito e igualitário.
- Cultura urbana conectada em uma única plataforma.
- Espaço aberto à comunidade, com responsabilidade e moderação.
- O site não é nosso: é da rua.

## Executar localmente

Abra o arquivo index.html em um navegador. As fontes são carregadas do Google Fonts; sem conexão, serão usadas fontes alternativas locais.
